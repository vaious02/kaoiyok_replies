# คลังคำตอบแชท · เก้าอี้โยก

เว็บหน้าเดียวสำหรับแอดมินเพจ กดคัดลอกคำตอบทีละบับเบิลแล้ววางในกล่องข้อความ Facebook ได้เลย
คนทั่วไปเปิดอ่านและคัดลอกได้โดยไม่ต้องล็อกอิน แต่เพิ่ม แก้ ลบ ต้องล็อกอินด้วยอีเมลและรหัสผ่านที่อยู่ในรายชื่อแอดมิน

ไฟล์ในโปรเจกต์
- `index.html` — ตัวเว็บทั้งหมด
- `config.js` — ใส่ค่าเชื่อมต่อ Supabase
- `schema.sql` — ตาราง สิทธิ์ และคำตอบตั้งต้น 19 ชุด

---

## 1. สร้างโปรเจกต์ Supabase

สร้าง project ใหม่ที่ supabase.com แล้วไปที่ **SQL Editor** วางทั้งไฟล์ `schema.sql` แล้วกด Run

ก่อน Run แก้บรรทัดนี้ให้เป็นอีเมลที่จะใช้ล็อกอินเป็นแอดมิน

```sql
values ('admin@kaoiyok.com', 'เจ้าของศูนย์')
```

เพิ่มแอดมินคนอื่นทีหลังได้ด้วย

```sql
insert into public.admins (email, note) values ('admin2@gmail.com', 'แอดมินเพจ');
```

## 2. สร้างบัญชีแอดมิน

ใช้ Email + Password ของ Supabase Auth ตรง ๆ ไม่ต้องต่อ Google

**Authentication → Users → Add user → Create new user**
ใส่อีเมลกับรหัสผ่าน แล้วติ๊ก **Auto Confirm User** ด้วย ไม่งั้นต้องไปกดยืนยันในเมลก่อนถึงจะเข้าได้

อีเมลที่ใส่ตรงนี้ **ต้องตรงกับอีเมลในตาราง admins** ถึงจะแก้ข้อมูลได้ ถ้าใส่ไม่ตรง จะล็อกอินผ่านแต่ปุ่มเพิ่มคำตอบไม่ขึ้น

ปิดการสมัครเองด้วย ที่ **Authentication → Sign In / Providers → Email** ปิดสวิตช์ *Allow new users to sign up* จะได้ไม่มีใครสมัครบัญชีเข้ามาเองได้

ส่วน **URL Configuration** ไม่ต้องตั้งก็ได้แล้ว เพราะไม่มีการ redirect ออกไปข้างนอก แต่ตั้งไว้ก็ไม่เสียหาย

## 3. ใส่ค่าใน config.js

เอาค่าจาก **Project Settings → API**

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://xxxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGci...'
};
```

anon key ใส่ในไฟล์ได้ ไม่เป็นความลับ สิทธิ์จริงคุมด้วย RLS ในฐานข้อมูล คนที่ไม่ได้อยู่ในตาราง `admins` ต่อให้แก้โค้ดหน้าเว็บก็เขียนข้อมูลไม่ได้

## 4. เปิดใช้งาน

ทดสอบเครื่องตัวเอง

```bash
npx serve .
```

เปิดผ่าน `http://localhost:3000` (เปิดไฟล์ตรง ๆ แบบ `file://` ไม่ได้ เพราะ OAuth ต้องมี origin)

ขึ้นออนไลน์ ลากโฟลเดอร์นี้ทั้งอันไปวางที่ Netlify Drop หรือ `vercel deploy` ก็ได้ ไม่มี build step
แล้วอย่าลืมเอา URL จริงไปใส่ใน Redirect URLs ของ Supabase

## วิธีใช้งานหน้าเว็บ

- **กดที่บับเบิลไหนก็ได้** คัดลอกเฉพาะบับเบิลนั้น สำหรับส่งทีละข้อความให้เหมือนคนพิมพ์
- **คัดลอกทั้งหมด** ได้ทุกบับเบิลต่อกัน เว้นบรรทัดคั่น
- ข้อความที่ไฮไลต์สีส้มใน `[วงเล็บ]` คือจุดที่ต้องเติมเอง จะมีจุดเตือนใต้การ์ดด้วย ห้ามวางทั้งอย่างนั้น
- ช่องค้นหากรองทั้งชื่อ คำถามลูกค้า และตัวข้อความ
- ปุ่มเพิ่มคำตอบมุมขวาล่างจะโผล่เฉพาะตอนล็อกอินเป็นแอดมิน
- ในฟอร์มเพิ่มคำตอบ **ขึ้นบรรทัดใหม่ 1 ครั้ง = แยกเป็นอีกบับเบิล**
- ติ๊ก "แสดงในคลัง" ออก เพื่อซ่อนคำตอบที่ยังไม่อยากให้ทีมใช้ โดยไม่ต้องลบ
