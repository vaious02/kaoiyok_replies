# Prompt สร้างโฆษณา Facebook · เก้าอี้โยก

ไฟล์นี้คือ prompt สำเร็จรูปสำหรับให้ AI (Claude / ChatGPT / Meta AI) เขียนชุดโฆษณา Facebook
วิธีใช้ คัดลอกทั้งบล็อกในหัวข้อ **prompt หลัก** ไปวาง แล้วแนบรูป 5 รูปตามลำดับในตาราง

---

## รูปที่ใช้ และหน้าที่ของแต่ละรูป

| ลำดับ | ไฟล์ / ภาพ | ใช้เป็น | มุมที่รูปนี้ขายได้ |
|---|---|---|---|
| 1 | หน้าบ้านเดี่ยวสีขาว มีรั้ว มีป้ายเก้าอี้โยก | ภาพหลักของแคมเปญ | บรรยากาศบ้านเดี่ยว ไม่ใช่ตึกโรงพยาบาล สะอาด อยู่ในหมู่บ้าน |
| 2 | เจ้าหน้าที่ประคองคุณยายเดินราวฝึกเดิน (แนวตั้ง) | Story / Reels / ภาพแนวตั้ง | ดูแลใกล้ชิดตัวต่อตัว ฟื้นฟูการเดิน มีคนอยู่ด้วยตลอด |
| 3 | ห้องพัก เตียงปรับระดับ ผู้สูงอายุ 2 ท่านนั่งคุยกัน | ภาพห้องพัก | เตียงจริงที่จะได้นอน ห้องโปร่ง มีเพื่อน ไม่เหงา |
| 4 | กิจกรรมวาดรูประบายสีเป็นกลุ่ม มีเจ้าหน้าที่ดูแล | ภาพกิจกรรม | มีกิจกรรมทุกวัน ไม่ได้นอนเฉย ๆ อัตราส่วนคนดูแลต่อผู้สูงอายุสูง |
| 5 | โลโก้ เก้าอี้โยก KAO I YOK ELDERLY CARE | ปิดท้าย / โปรไฟล์ / รูปสุดท้ายในคารูเซล | แบรนด์ ชื่อร้าน จำง่าย |

## prompt หลัก (คัดลอกทั้งบล็อกนี้)

```
คุณเป็นนักเขียนโฆษณา Facebook ที่ถนัดตลาดศูนย์ดูแลผู้สูงอายุในไทย
ช่วยเขียนชุดโฆษณา Facebook ให้ "เก้าอี้โยก" จากรูป 5 รูปที่แนบมา

# ข้อมูลธุรกิจ (ห้ามแต่งเพิ่มเกินจากนี้)
- ชื่อ: เก้าอี้โยก (Kao I Yok Elderly Care) ศูนย์ดูแลผู้สูงอายุ
- ที่ตั้ง: ซอยประเสริฐมนูกิจ แขวงจรเข้บัว เขตลาดพร้าว กรุงเทพฯ ย่านเกษตร-นวมินทร์
- ลักษณะ: บ้านเดี่ยว 2 ชั้น ไม่ใช่ตึกหรือโรงพยาบาล อยู่ในหมู่บ้าน เงียบ สะอาด
- รับได้ 10 เตียงเท่านั้น จำนวนจำกัด
- มีเจ้าหน้าที่ดูแลตลอด 24 ชั่วโมง
- รับดูแลทั้งท่านที่ช่วยเหลือตัวเองได้ ท่านที่ต้องพยุง และเคสติดเตียง
- มีกิจกรรมประจำวัน เช่น ฝึกเดิน กายภาพเบา ๆ งานศิลปะ
- ราคา: รายเดือน 29,000 บาท / รายสัปดาห์ 9,900 บาท / รายวัน 900 บาท
  รวมที่พัก อาหาร 3 มื้อ ผ้าอ้อม ซักรีด และคนดูแล 24 ชม. ไม่มีบวกเพิ่ม
  ส่วนที่จ่ายเพิ่มมีเฉพาะของใช้ส่วนตัวและค่ายาประจำตัว
- เยี่ยมชมสถานที่ได้ฟรี ไม่มีค่าใช้จ่าย ไม่ต้องนัดล่วงหน้า เข้าชมได้ 08:00-17:00 ทุกวัน
- ญาติเข้าเยี่ยมได้ทุกวันในเวลาเดียวกัน
- ติดต่อ: โทร 099-569-1442 หรือทักแชทเพจ

# สิ่งที่ทุกชิ้นงานต้องมีครบ
1. รับแค่ 10 เตียง จำนวนจำกัด
2. เยี่ยมชมสถานที่ได้ฟรี ไม่มีค่าใช้จ่าย
3. มีทั้งแบบรายเดือนและรายวัน (เลือกได้ ไม่ต้องผูกมัด)
4. บรรยากาศบ้านเดี่ยว ไม่ใช่ตึก

# กลุ่มเป้าหมาย
ลูกหลานวัย 35-60 ปี ทำงานประจำ ดูแลพ่อแม่เองไม่ไหว รู้สึกผิดที่ต้องฝากคนอื่น
กังวล 3 เรื่อง คือ ท่านจะถูกทิ้งไว้เฉย ๆ ไหม สะอาดจริงไหม และราคาจะบานปลายไหม
เขียนให้พูดกับความรู้สึกนี้ ไม่ใช่พูดกับตัวผู้สูงอายุ

# โทนเสียง
- ภาษาพูดแบบคนไทยคุยกันจริง สุภาพ ลงท้ายด้วย ค่ะ
- อบอุ่น ตรงไปตรงมา ไม่ดราม่า ไม่ขายความน่าสงสาร ไม่ใช้คำว่า "ทิ้งพ่อแม่"
- ห้ามขึ้นต้นด้วยราคา ให้พูดเรื่องความสบายใจก่อนแล้วค่อยบอกราคา
- ปิดท้ายด้วยคำชวนคุยหรือคำถามเสมอ ไม่จบห้วน ๆ
- ห้ามใช้อีโมจิเกิน 3 ตัวต่อชิ้น ห้ามใช้ตัวพิมพ์ใหญ่ทั้งประโยค
- ห้ามเคลมทางการแพทย์ เช่น รักษาหาย ฟื้นฟูได้ 100% ปลอดภัยที่สุด ดีที่สุดในย่าน

# ข้อกำหนดของ Facebook ที่ต้องเลี่ยง
- ห้ามชี้ตัวตนผู้อ่านตรง ๆ แบบ "คุณกำลังป่วยติดเตียงใช่ไหม" หรือ "พ่อแม่คุณเป็นอัลไซเมอร์"
  ให้เขียนแบบกลาง ๆ เช่น "หลายบ้านที่มาปรึกษา เจอปัญหาเดียวกันคือ..."
- ห้ามสัญญาผลลัพธ์ด้านสุขภาพ
- ห้ามใช้ข้อความข่มขู่ให้กลัว

# สิ่งที่ต้องส่งกลับมา
ทำ 4 ชุดโฆษณา แต่ละชุดจับคู่กับ 1 รูปตามนี้
- ชุด A ใช้รูปหน้าบ้าน — มุม "บรรยากาศบ้านเดี่ยว รับแค่ 10 เตียง"
- ชุด B ใช้รูปเจ้าหน้าที่ประคองเดิน — มุม "ดูแลใกล้ชิด 24 ชม."
- ชุด C ใช้รูปห้องพัก — มุม "เตียงจริงที่ท่านจะได้นอน มาดูก่อนได้ฟรี"
- ชุด D ใช้รูปกิจกรรมวาดรูป — มุม "ไม่ได้นอนเฉย ๆ มีกิจกรรมทุกวัน"

แต่ละชุดส่งมาแบบนี้
1. Primary text 2 แบบ (แบบสั้น 2-3 บรรทัด และแบบยาว 5-8 บรรทัด) แบบยาวให้เว้นบรรทัดอ่านง่าย
2. Headline ไม่เกิน 40 ตัวอักษร 3 ตัวเลือก
3. Description ไม่เกิน 30 ตัวอักษร 1 อัน
4. ปุ่ม CTA ที่ควรใช้ (Send Message / Learn More / Call Now) พร้อมเหตุผลสั้น ๆ
5. ข้อความ overlay บนรูป ไม่เกิน 7 คำ เผื่อเอาไปใส่บนภาพ

จากนั้นเพิ่มอีก 3 ส่วน
- แคปชันคารูเซล 1 ชุด ที่ใช้รูปทั้ง 5 รูปเรียงตามลำดับ หน้าบ้าน / ฝึกเดิน / ห้องพัก / กิจกรรม / โลโก้
  เขียนข้อความสั้นประจำแต่ละสไลด์ 1 บรรทัด และ primary text ของโพสต์รวม 1 อัน
- สคริปต์ Reels 15 วินาที ใช้รูปแนวตั้ง (รูปฝึกเดิน) เป็นภาพเปิด แยกเป็นวินาทีกับข้อความบนจอ
- ข้อความตอบอัตโนมัติเมื่อมีคนทักแชทจากโฆษณา 1 ชุด ปิดท้ายด้วยการชวนมาดูสถานที่ฟรี
  และขอชื่อกับเบอร์เพื่อเช็กเตียงว่างให้

ห้ามใส่ราคาลงบนรูป ให้ราคาอยู่ในข้อความเท่านั้น
ทุกชิ้นต้องมีเบอร์ 099-569-1442 หรือคำชวนทักแชท
```

## prompt เสริม สำหรับสร้างภาพโฆษณาจากรูปเดิม

ถ้าจะให้ AI ทำภาพโฆษณาพร้อมข้อความ ใช้ prompt นี้ต่อท้าย พร้อมแนบรูปที่ต้องการ

```
ออกแบบภาพโฆษณา Facebook ขนาด 1:1 (1080x1080) จากรูปที่แนบ
- ใช้รูปเดิมเป็นพื้นหลัง ห้ามเปลี่ยนหน้าคนหรือแต่งสภาพสถานที่ให้ผิดจากของจริง
- โทนสีตามโลโก้ น้ำตาลไม้ ครีม เขียวใบไม้อ่อน
- วางโลโก้เก้าอี้โยกมุมบนซ้ายหรือล่างขวา ขนาดไม่เกิน 15% ของภาพ
- ข้อความบนภาพไม่เกิน 7 คำ ตัวหนา อ่านออกบนมือถือ เช่น "บ้านเดี่ยว รับแค่ 10 เตียง"
- มีแถบเล็ก ๆ ด้านล่างเขียนว่า "เยี่ยมชมฟรี 08:00-17:00 · โทร 099-569-1442"
- พื้นที่ตัวอักษรรวมกันไม่เกิน 20% ของภาพ เพราะข้อความเยอะทำให้ค่าโฆษณาแพงขึ้น
- ห้ามใส่ราคาบนภาพ
```

## เช็กก่อนกดยิงโฆษณา

- ตัวเลขราคาตรงกับที่ใช้ตอบแชทจริง 29,000 / 9,900 / 900
- ระบุ 10 เตียง จำนวนจำกัด และ เยี่ยมชมฟรี ครบทุกชิ้น
- ไม่มีคำเคลมรักษาหายหรือ "ดีที่สุด"
- ไม่ได้ชี้ตัวผู้อ่านว่าป่วยหรือมีโรคอะไร
- ตั้งข้อความตอบอัตโนมัติในเพจไว้แล้ว คนทักมาแล้วไม่เงียบ
